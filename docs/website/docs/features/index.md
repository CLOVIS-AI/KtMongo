# Navigating the KtMongo documentation

The documentation is categorized in three sections:

- **Getting started**: discover and configure KtMongo, flavor-specific functionality
- **Features**: discover what KtMongo can do
- **Reference**: exhaustive documentation of all types and methods

To learn about the different KtMongo features, choose an article in the sidebar, for example [CRUD operations](crud.md).
